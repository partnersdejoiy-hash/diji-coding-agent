Set up

  1. Telegram: message @BotFather, send /newbot, copy the token into TELEGRAM_BOT_TOKEN.
  2. Slack: create an app at api.slack.com/apps with scopes app_mentions:read, im:history, chat:write; set Event Subscriptions URL to https://YOUR-SERVER/api/channels/slack with events app_mention and message.im; put the bot token in SLACK_BOT_TOKEN and the signing secret in SLACK_SIGNING_SECRET.
  3. WhatsApp: set WHATSAPP_ENABLED=1, then scan the QR code here. Diji answers in your "Message yourself" chat and to numbers on the allow list. It is unofficial, so WhatsApp may restrict the number; a spare number is safest.
  4. Put the ids or numbers allowed to talk to Diji in DIJI_CHANNEL_ALLOW (comma separated). Unknown Telegram and Slack users are told their id.
  5. Add these to server/deploy/.env on the VM, then run sudo docker compose up -d --build.
