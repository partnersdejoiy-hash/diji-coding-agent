# Bold Brutalist UI

- Structure is the decoration: visible grids, thick 2–4px borders, hard corners (radius 0), blocky sections.
- Type: an oversized condensed or grotesk display face (clamp up to ~8rem), uppercase used deliberately, tight leading. Mono only for data and code.
- Colour: high contrast. Black, white and one or two loud signal colours (acid yellow, safety orange, electric blue).
- Shadows, if any, are solid offset blocks (e.g. `6px 6px 0 #000`) used consistently, because this world chose them.
- Interactions are blunt and fast: invert colours on hover, translate 2px on press, no soft easing.
- Keep it usable: contrast still passes WCAG, tap targets ≥ 44px, focus states as loud as hover states.
