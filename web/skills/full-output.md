# Full Output

- A partial file is a broken file. When writing or changing a file, send the whole file.
- Banned: `// ...`, `// rest of code`, `// TODO: implement`, `/* same as above */`, bare `...` standing in for code, "the rest follows the same pattern".
- If you were asked for N things (files, functions, sections), count them before finishing and deliver all N.
- If the output is genuinely too long for one reply, stop at a clean boundary (end of a file) and write: `[PAUSED — X of Y files done. Say "continue" for: <next file>]`. On "continue", resume exactly there without repeating.
