# Brand-Style Design

When asked for "like Stripe / Linear / Apple / Vercel / Notion":
1. Capture the language, not the property. Never use their logo, name, wordmark, mascot or screenshots. Invent the product name and copy.
2. Write a short DESIGN brief first: palette (as hex tokens), type character, radius, density, shadow style, motion feel, signature layout move.

Reference languages:
- Stripe-like: deep navy and soft white, one vivid accent, angled colour washes behind hero, crisp sans, generous product mockups, small uppercase-free labels.
- Linear-like: near-black UI, subtle 1px borders, tight dense type, monochrome with one accent, keyboard-first, fast micro-interactions.
- Apple-like: huge confident headlines, product as hero, lots of white or black space, short sentences, scroll-driven reveals.
- Vercel-like: black and white, geometric sans and mono, grid lines, terminal snippets, sharp contrast.
- Notion-like: warm white, serif headings option, friendly illustrations, quiet grey UI chrome, block-based layouts.

Then build with the brief as CSS variables and keep it consistent across every component.
