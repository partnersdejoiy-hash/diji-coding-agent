# Minimalist UI

- Palette: a warm off-white (#F7F5F2 range) and near-black ink (#1A1917 range), one muted pastel accent used sparingly for state. No gradients.
- Type does the work: a serif or refined grotesk for display, a quiet sans for body. Contrast through size and weight, not colour.
- Layout: flat bento or column grids with thin 1px rules instead of boxes. Lots of whitespace; let one element per view be clearly primary.
- Depth: almost none. If you need elevation, one soft shadow (0 1px 2px + 0 8px 24px at low opacity).
- Motion: short opacity and position fades (150–250ms, ease-out). Nothing bounces.
- Remove before adding: every border, label and icon must earn its place.
- Keep controls obvious: minimal does not mean hidden. Buttons still look clickable; focus rings stay visible.
