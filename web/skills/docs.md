# Docs & READMEs

A README answers, in this order:
1. What it is, in one sentence, plus a screenshot or GIF.
2. Why it matters / key features (3–6 bullets with substance).
3. Quick start: prerequisites, then copy-paste commands that actually work, in order.
4. Configuration: every env var with a description and example value.
5. Deploy: the shortest path to production.
6. Architecture: a small diagram (Mermaid) and where the main code lives.
7. Contributing, license.

Write for a busy reader: short sentences, real commands, no marketing fluff. Verify every command and path you list exists.
