# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (responsive: phone, tablet, laptop, desktop)

## Stack

Static HTML/CSS/ES modules with no build step (`web/`), Vercel functions for the model proxy, a Node + Playwright server on an Oracle Cloud Always Free VM for the cloud browser. Already built; keep it.

## Users

Everyone who codes with Dejoiy: it is Dejoiy's official coding tool for all users, from students to professional developers. They open it to build, fix or understand code, often in long sessions, on laptops and phones, in daylight and at night.

## Product Purpose

Diji is a coding agent that writes complete, runnable files, previews them live, and looks things up in a real cloud browser. Success: a person goes from an idea or a bug to working code they can download or ship, without leaving the chat.

## Positioning

Model-agnostic by design: bring your own key for any major provider, any OpenAI- or Anthropic-compatible endpoint, or self-hosted open models, plus a keyless free tier. Skills (Markdown playbooks, importable) steer how it works. It belongs to Dejoiy and carries Dejoiy's joy ("You + Joy").

## Brand commitments

- Dejoiy brand colours come from the logo: magenta `#F0218F`, violet `#8B3DF0`, blue `#2F6BFF`, deep navy ink. Respect them, but the user rejected the blue/purple "AI app" look: no navy-dominant surfaces, no blue-purple gradients as decoration.
- Mascot: Diji, an original round pink mochi blob with a small glowing sprout on its head, small dark bean eyes and blushing cheeks; it squishes while working. Must stay original and must not resemble any existing franchise character.
- Light and dark themes must both be first-class; never dark-only.

## Voice

Warm, direct, a little playful. Plain words, no hype. Hinglish-friendly audience, English UI copy.
